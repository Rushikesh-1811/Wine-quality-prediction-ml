
# 🍷 Wine Quality Prediction using Machine Learning

## 📌 Project Overview
This project predicts wine quality (Average, Good, Excellent) using physicochemical properties like acidity, alcohol, pH, sulphates, etc.  
It helps automate wine quality assessment for real-world production decision making.

---

## 🎯 Problem Statement
Wine quality evaluation is traditionally subjective and depends on human experts.  
This project builds a machine learning classification model to predict wine quality consistently and efficiently.

---

## 📊 Dataset
- Wine Quality Dataset
- 5320 rows, 16 features
- No missing values
- Target: Quality (converted into categories)

---

## 🧪 EDA Performed
- Univariate Analysis (distribution & outliers)
- Bivariate Analysis (feature relationships)
- Multivariate Analysis (correlation heatmap)

Key Insight:
- Alcohol & Sulphates → Positive impact
- Volatile Acidity → Negative impact

---

## 🤖 Models Used
- Logistic Regression
- Decision Tree
- Random Forest (Bagging Ensemble)
- Gradient Boosting (Boosting Ensemble)
- Support Vector Classifier (SVC)
- K-Nearest Neighbors (KNN)

Best model selected based on:
Accuracy, Precision, Recall, F1-score

---

## ⚙️ ML Techniques Applied
- Data Preprocessing & Cleaning
- Feature Scaling (StandardScaler)
- Handling Imbalanced Data (Random Over-Sampling)
- Model Training & Evaluation

---

## 🚀 Deployment
Interactive Streamlit dashboard for real-time wine quality prediction.

## 📌 Business Impact
